# Pooprunner 3D

A first-person dog-park game: clear the poops with a toilet-paper blaster, then beat King Poop.

Play: [pooprunner.lol/3d](https://pooprunner.lol/3d/), or open `index.html` in a browser (works offline).
Test: `node 3d/tests/run.mjs [filter]` (needs Node 22+ and Google Chrome; set `CHROME` to the browser's path if it isn't the macOS default).
