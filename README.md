# Poop Runner

The games at [pooprunner.lol](https://pooprunner.lol), served by GitHub Pages from this repo.

- `index.html`: the menu, to pick a game
- `2d/`: Poop Runner, the original. Jump the poops.
- `3d/`: Poop Runner 3D. Clean up the dog park with a toilet-paper blaster, then beat King Poop.

Each page is a single self-contained HTML file and works offline.
